# SEND IT — Downhill MTB

A fast, arcade downhill mountain biking game built with a single Canvas 2D scene and no dependencies.

Ride a procedurally generated trail, hit kickers, backflip and frontflip, throw style grabs, chain combos, and boost. Land with your wheels lined up or eat dirt. Three wipeouts ends the run.

**Play:** https://daproatgames.github.io/send-it/

## Controls

| Input | Action |
| --- | --- |
| `→` / `D` | Sprint (the bike auto-pedals) |
| `←` / `A` | Brake |
| `↑` / `W` / `Space` | Ollie, then backflip in the air |
| `↓` / `S` | Tuck, then frontflip in the air |
| `Shift` | Style grab |
| `B` | Boost |
| `M` | Mute |
| `R` | Ride again after a wipeout |

Touch controls are available on phones and tablets.

## Run locally

Open `index.html` in a browser. That's it.
